# Bio-link страница

Небольшая статическая страница с профилем, ссылками и фоновым видео. Для работы не нужны зависимости, сборка или серверная часть.

Все настройки профиля находятся в [js/config.js](js/config.js). Обычно достаточно менять только этот файл.

## Быстрый старт

1. Замените файлы в папке `assets/` своими: аватар, видео, иконки и бейджи.
2. Откройте `js/config.js` и укажите имя, статус, ссылки и пути к файлам.
3. Запустите сайт через локальный HTTP-сервер или загрузите его на статический хостинг. Не открывайте страницу напрямую через `file://`: браузер может не загрузить видео или шрифт.

Для локальной проверки из корня проекта:

```powershell
py -m http.server 8000
```

Затем откройте `http://127.0.0.1:8000/`.

## Что настраивается

| Раздел | Назначение |
| --- | --- |
| `profileName`, `statusText`, `tabTitle` | Имя, статус и заголовок вкладки |
| `avatar`, `backgroundVideo`, `customCursor` | Пути к аватару, фоновому видео и курсору |
| `badges` | Значки рядом с именем |
| `discordUsername`, `discordStatus`, `discordAvatar` | Блок Discord без обращения к API |
| `socialLinks` | Ссылки на социальные сети |
| `cardBackground`, `cardBorderRadius`, `cardTiltIntensity` | Внешний вид и наклон карточки |
| `particleColor`, `particleCount` | Фоновые частицы |
| `musicTracks`, `musicVolume` | Плейлист и громкость встроенного плеера |

## Структура

```text
index.html        разметка страницы
css/style.css     стили
js/config.js      настройки профиля
js/script.js      логика страницы
assets/           изображения, шрифт и видео
```

## Файлы в `assets/`

| Файл или папка | Назначение |
| --- | --- |
| `avatar.jpg` | Аватар профиля |
| `discord-avatar.jpg` | Аватар в блоке Discord |
| `background.mp4` | Фоновое видео |
| `cursor.png` | Пользовательский курсор |
| `favicon.png` | Иконка вкладки |
| `badges/` | Значки ролей |
| `icons/` | Иконки социальных сетей и статусов |
| `fonts/fuente.otf` | Шрифт страницы |
| `music/` | Музыка плеера в формате `.mp3` |

## Лицензия

Проект можно свободно использовать и изменять.
